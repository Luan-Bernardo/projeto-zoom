# 📰 Projeto Zoom Clone

Este é um projeto front-end criado como exercício prático para aplicar os conceitos de **HTML** e **CSS**, inspirado em uma landing page da plataforma Zoom. O foco principal foi treinar estruturação semântica, estilização com **CSS Grid** e responsividade com media queries.

## 🔗 Acesse o site:
➡️ [Clique aqui para ver o projeto publicado no GitHub Pages](https://luan-bernardo.github.io/projeto-zoom/)

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Grid Layout
- Flexbox
- Responsividade com media queries
